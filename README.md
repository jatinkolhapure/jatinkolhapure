**Technologies:** Java 21, Spring Boot, Kafka, Redis, PostgreSQL, Docker, Azure

NexusPay is a payment platform I developed to explore secure payment processing and communication between backend services.

- Built a seven-service architecture covering payment processing, merchant management, fraud detection, ledger operations, notifications, webhooks, and API routing.
- Implemented JWT/OAuth2 authentication, role-based access control, rate limiting, audit logging, and idempotency.
